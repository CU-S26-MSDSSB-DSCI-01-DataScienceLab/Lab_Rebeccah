4. Data Audit, Normalizing Dimensions

4.1 Detecting the change in the survey answering scales

The rating scales used in the survey changed across cohorts. The earlier cohorts used rating scales that began at 1 and went up to 5 or 7, depending on the year. In contrast, the 2025 cohort used a 0–10 scale.

The min–max table above (Section 3) shows this clearly for each year.

Summary. Because the range of possible scores differs between cohorts, the raw values are not directly comparable across years. When comparing skills across cohorts, we must account for these scale differences — otherwise some cohorts may appear stronger or weaker simply because they used a different scoring scale.

4.2 Normalization idea

  1. How to construct a normalized variable. Use Min–Max scaling within each individual so their minimum becomes 0 and maximum becomes 10: [ = ] This aligns scales across years and ensures each profile spans 0–10.

  2. Drawbacks. Scores become relative to each person (harder cross-person comparisons); tiny within-person ranges can exaggerate differences; absolute meaning is reduced.

  3. Which scale is better and why. A 0–10 scale is clearer: 0 means absence of skill and 10 means highest skill. A 1–10 scale compresses the low end and blurs “no skill” vs. “very low”.

In this section, we explore the results of the Principal Component Analysis (PCA). There are r length(PCA$sdev) principal components in total.

The standard deviations of the components are r paste(round(PCA$sdev, 3), collapse = “,”).

The variances (squared deviations) are r paste(round(PCA$sdev^2, 3), collapse = “,”).

The total variance is r round(sum(PCA$sdev^2), 3).

The percentages of variance explained by each component are r paste(round(100 * (PCA\(sdev^2 / sum(PCA\)sdev^2)), 1), collapse = “%,”)%.

The cumulative percentages are r paste(round(cumsum(100 * (PCA\(sdev^2 / sum(PCA\)sdev^2))), 1), collapse = “%,”)%.

Quantitative Model Description

The linear regression analyses examine how different aspects of data science skills—Mathematics, Data Visualization, Machine Learning, and Statistics—relate to Programming performance.

In the first set of models, Mathematics, Data Visualization, and Machine Learning were each used separately to predict Programming scores.
All three predictors show positive relationships with Programming, meaning that students who score higher in these areas also tend to have higher Programming scores.
However, the strength of the association varies: Mathematics often shows the strongest linear relationship, while Data Visualization and Machine Learning show slightly weaker, though still positive, effects.

When all three predictors are combined in a full model, we can assess how each contributes while controlling for the others.
In this model, some predictors may lose significance, indicating shared variance—for example, strong overlap between Mathematics and Machine Learning.
This suggests these skills develop together and jointly explain Programming ability.

In the second set of models, Statistics and Type (Instructor vs. Student) are included.
Adding Type as a factor allows us to see whether instructors differ systematically from students in Programming outcomes.
The interaction term Statistics * Type checks whether the effect of Statistics on Programming is different for instructors than for students.

Overall, the quantitative results show that Programming skills are positively associated with core data science dimensions.
Mathematics tends to be the most consistent predictor, while Statistics also plays an important role.
Including Type helps identify whether teaching experience or role influences these relationships, offering deeper insight into patterns of skill development across groups.
